# Innova Dental Clinic — Website

A modern, premium, and responsive frontend website project built for a dental clinic landing page.

## ✨ Features

* Modern premium UI/UX
* Fully responsive layout
* Mobile-first design
* Responsive navigation
* Hero section with CTA
* Services section
* Doctors/experts section
* Testimonials section
* Contact section
* WhatsApp CTA integration
* Google Maps integration
* Smooth scrolling
* Scroll reveal animations
* Hover micro-interactions
* Reduced-motion accessibility support

## 🛠️ Tech Stack

* HTML5
* Tailwind CSS
* CSS3
* Vanilla JavaScript
* Google Fonts
* Font Awesome / SVG Icons

## 📁 Project Structure

```text
innova-dental-clinic/
│
├── index.html
└── README.md
```

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/innova-dental-clinic.git
```

Navigate to the project:

```bash
cd innova-dental-clinic
```

Open `index.html` in your browser.

No installation or build process is required.
